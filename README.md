# 🚍 Smart Transit Optimisation

A mini project that aims to make public transit more efficient by analysing transit data and optimising routes, schedules and resource usage.

---

## 📌 Overview

Public transport systems often suffer from overcrowding, long waiting times, inefficient routes and poor use of vehicles. This project explores how data-driven techniques can help improve transit planning so that passengers travel faster and operators use their resources better.
